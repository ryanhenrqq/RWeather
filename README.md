# RWeather - Clima instantâneo

- Rweather é um site para consultar as condições climaticas de uma cidade, fornecendo informações basicas e de facil acesso.

- O intuito é ser uma ferramenta que prioriza o entendimento do usuário, sem nada tecnico. Além disso, é pra ser automatizado e exigir o minimo de cliques e esforço do mesmo.

- Este é um website escrito em TypeScript (otimizado pro mesmo tambem), criado pela ferramenta Vite, e com o deploy sendo feito no Vercel, além de ser hospedado pelo mesmo também.
